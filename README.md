# داینر | Diner

[![CI](https://github.com/nimania/diner/actions/workflows/ci.yml/badge.svg)](https://github.com/nimania/diner/actions/workflows/ci.yml)

دستیار فارسی و راست‌به‌چپ برای رستوران‌ها و کافه‌های مستقل: مواد و قیمت، دستور غذا، ترکیب گوشت، خرید و موجودی، دورریز، فروش و گزارش روزانه.

**[شروع از مستندات کامل](documentation/README.md)** · [راهنمای استفاده](documentation/USER_GUIDE.fa.md) · [راهنمای توسعه](documentation/DEVELOPMENT.fa.md) · [نقشه راه](documentation/ROADMAP.fa.md)

## نسخه‌های پروژه

| مسیر | کاربرد | وضعیت |

[برنامه آنلاین](https://diner-nima-workspace.iran.chatgpt.site) · [پیش‌نمایش عمومی نقش‌ها](https://nimania.github.io/diner/)

عمومی‌بودن مخزن به معنی عمومی‌بودن حساب رستوران، پایگاه داده یا دسترسی به برنامه آنلاین نیست. در این تغییر مستنداتی مجوز حقوقی جدیدی برای کد تعیین نشده است.

## قابلیت‌های موجود

- کتابخانه ۱۳۷ ماده و ملزومات و ۳۶ الگوی غذا/نوشیدنی؛ جست‌وجو، نماد تصویری و افزودن مورد دلخواه.
- قیمت همراه منبع؛ دستورها با نسخه‌ای از مقدارها و قیمت زمان ثبت.
- ترکیب داخلی گوشت با ۲ تا ۸ جزء و مجموع دقیق ۱۰۰٪؛ چند ترکیب مستقل و اصلاح نسخه‌دار.
- خرید با مقدار، فروشنده، محل و تاریخ روی بسته؛ دورریز مرتبط با همان خرید.
- فروش دستی حضوری، بیرون‌بر و اسنپ؛ کسر مواد طبق دستور، محاسبه هزینه از خریدهای مصرف‌شده.
- ساخت منوی عمومی با نام، توضیح، دسته‌بندی و قیمت؛ لینک نسخه ثابت، بدون سفارش یا پرداخت.
- رنگ بنفش مدیر کل نمایشی، سبزآبی مدیر رستوران و نارنجی بخش عمومی.
- گزارش روز تهران با تخفیف، کمیسیون، بسته‌بندی، پیک و دورریز؛ **مبلغ باقی‌مانده، سود خالص نیست**.
- فضای تستی جدا با مواد، ترکیب‌ها، خریدها، فروش‌ها و دورریز فرضی؛ ورود خودکار نمونه‌ها هنگام بازکردن فضای تستی.

هنوز اتصال مستقیم اسنپ یا دیجی‌کالا، ورود فایل حسابداری، اجاره و حقوق و قبوض، پنل واقعی مدیر کل، دعوت کارکنان و چت‌بات عملیاتی نداریم. محدودیت مهم فعلی: API حداکثر ۱۰۰۰ رکورد و ۱۰۰۰ حرکت دورریز را برمی‌گرداند؛ گزارش تاریخی کامل برای حجم بالا آماده نیست.

## توسعه سریع نسخه آنلاین

```bash
git clone https://github.com/nimania/diner.git
cd diner/hosted
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
node tests/operations.test.mjs
pnpm build
```

Node.js 22.13 یا بالاتر و نسخه pnpm مشخص‌شده در `hosted/package.json` لازم است. اجرای کامل آنلاین به D1 و هویت معتبر درگاه Sites وابسته است؛ clone و build به‌تنهایی ورود کاربران را روی میزبان دیگری فراهم نمی‌کند. [جزئیات راه‌اندازی و انتشار](documentation/DEVELOPMENT.fa.md).
