# Security Policy

## Reporting a vulnerability

Please do not publish credentials, access tokens, private customer data, or exploitable security details in a public issue.

If you discover a security issue, report it privately to the repository owner through an appropriate private contact channel. Include:

- affected component or path;
- steps to reproduce;
- potential impact;
- any suggested mitigation, if known.

## Supported code

The actively developed online application is under `hosted/`. Legacy or prototype code may remain in the repository for reference and should not be assumed to receive the same level of maintenance.

## Secrets

No production secrets, API keys, database credentials, or private user data should be committed to this repository.
