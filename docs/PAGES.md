# پیش‌نمایش پنل‌ها
این پوشه شامل نسخه استاتیک نمایشی با داده‌های فرضی است؛ به پایگاه داده برنامه Python متصل نیست.
تغییرات فقط در حافظه همان صفحه‌اند و با reload پاک می‌شوند. اطلاعات واقعی وارد نکنید.
نقش‌ها صرفاً پیش‌نمایش هستند و احراز هویت یا مجوز امنیتی ایجاد نمی‌کنند.

## فعال‌سازی GitHub Pages
در Settings → Pages:
Source: Deploy from a branch
Branch: main
Folder: /docs
Save

امکانات نمایشی: دو نقش، داشبورد، جدول منو، محاسبه سناریوی هزینه،
ثبت موقت دورریز، فیلتر و جست‌وجوی مجموعه‌ها، وضعیت منابع و جدول دسترسی‌ها.
سایر ماژول‌ها صریحاً با عنوان برنامه ساخت مشخص‌اند.
GitHub Pages فقط این پیش‌نمایش استاتیک را ارائه می‌کند؛ برنامه عملیاتی به backend و ورود امن نیاز دارد.
