## واژه‌های مهم

- **رسپی/دستور:** مقدار مواد برای یک خروجی مشخص؛ خروجی لزوماً یک پرس نیست.
- **نسخه ثبت‌شده یا snapshot:** کپی مقدار و قیمت در زمان ثبت؛ تغییر امروز آن را بازنویسی نمی‌کند.
- **نوبت خرید / lot:** مقدار مشخص از یک خرید با قیمت و تاریخ مستقل.
- **بازده:** سهم قابل‌استفاده از ماده خام، به درصد.
- **مبلغ باقی‌مانده / contribution:** فروش پس از هزینه‌های مستقیم؛ هنوز هزینه‌های جاری و استهلاک کسر نشده‌اند.
- **تستی:** داده فرضی برای آزمودن جریان کار، نه قیمت بازار یا عملکرد واقعی.
- **ثبت بدون تکرار / idempotency:** تکرار همان شناسه درخواست نباید عملیات مالی یا انبار را دوباره اعمال کند؛ شناسه را برای عملیات متفاوت استفاده نکنید.

برای گزارش خطای مستندات، [Issue](https://github.com/nimania/diner/issues) با مسیر سند و رفتار مشاهده‌شده ثبت کنید. اطلاعات شخصی، فاکتور واقعی و کلید دسترسی را در Issue عمومی نگذارید.
