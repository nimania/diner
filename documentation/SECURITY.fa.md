# امنیت، حریم خصوصی و داده

## مرز اعتماد

نسخه آنلاین هویت را از headerهای `oai-authenticated-user-*` درگاه Sites می‌خواند. این روش فقط پشت درگاهی معتبر است که هدرهای ورودی کاربر را کنترل و هویت را خودش تزریق کند. Worker با اعتماد مستقیم به header کاربر نباید مستقل عمومی شود.

POST Origin را کنترل می‌کند؛ queryها پارامتری‌اند. دسترسی رکورد و خرید با restaurant_id محدود می‌شود. این‌ها کنترل‌های موجودند، نه ادعای ممیزی امنیت جامع. rate limiting اختصاصی، audit جامع و مدیریت نقش کارکنان هنوز وجود ندارند.

## داده خصوصی و عمومی

منبع کد و مستندات عمومی‌اند. دیتابیس D1، نام حساب، هزینه، دستور، فاکتور و موجودی عمومی نیستند. فضای تستی با owner مشتق از حساب جدا می‌شود؛ هویت واقعی کاربر نباید در خروجی مستندات/نمونه‌ها قرار گیرد.

منوی عمومی فقط داده مجاز مشتری را از دستور برمی‌دارد: نام غذا، قیمت فروش، توضیح و دسته. هیچ field خام recipe یا cost به خروجی منتقل نمی‌شود. صفحه عمومی روی GitHub Pages داده را از بخش fragment لینک می‌خواند و با textContent نمایش می‌دهد؛ HTML ورودی اجرا نمی‌شود. منو بارگیری API خصوصی ندارد.

محتوای fragment قابل خواندن و تغییر توسط دارنده لینک است و امضای تأییدشده ندارد. صفحه تأیید هویت رستوران ارائه نمی‌دهد. لینک را عمومی فرض کنید؛ اطلاعات محرمانه را در نام/توضیح منو وارد نکنید. انتشار نسخه جدید لینک قبلی را باطل نمی‌کند. برای هویت تأییدشده و ویرایش مرکزی، معماری انتشار عمومی جدا لازم است.

## اسرار و نسخه پشتیبان

توکن GitHub/Sites، کلید API، cookie، فایل داده واقعی، اطلاعات تماس مشتری و فاکتور را commit نکنید. فایل تنظیم binding منطقی جای credential نیست. در پروژه فعلی OpenAI API و کلید آن برای چت‌بات وجود ندارد.

سیاست retention، export، حذف حساب و restore محصول هنوز تکمیل نشده است. برای داده واقعی، backup و آزمون بازیابی باید قبل از اتکای عملیاتی تعیین شود. این سند مکان جغرافیایی یا رمزنگاری اختصاصی تأییدنشده را تضمین نمی‌کند.

## گزارش مشکل

خطای عمومی بدون داده حساس را در [Issues](https://github.com/nimania/diner/issues) گزارش کنید. برای آسیب‌پذیری همراه جزئیات قابل سوءاستفاده از قابلیت خصوصی گزارش امنیتی GitHub، اگر فعال است، استفاده کنید؛ در غیر این صورت ابتدا فقط درخواست کانال خصوصی از نگهدارنده کنید. نشانی امنیتی یا SLA پاسخ‌گویی تأییدشده‌ای تعیین نشده است.
