# آزمون‌ها و محدودیت‌ها

## آزمون خودکار موجود

از hosted اجرا کنید: `node tests/operations.test.mjs`.

پوشش فعلی: جمع درصد ترکیب، رد جزء تکراری، میانگین قیمت وزنی، شکستن ترکیب به گوشت خام، بازده، کسری، حذف تاریخ گذشته، contribution، seed کامل با SQLite، تکرار seed بدون تغییر موجودی، تعداد فروش/دورریز نمونه و رد دستور مجموعه دیگر.

این فایل همه مسیرهای HTTP و رفتار مرورگر را تست نمی‌کند. در توسعه اولیه، SQL فروش جداگانه برای retry، کسری و rollback خطای میانی هم بررسی شده؛ آن آزمایش مستقل به معنی پوشش پایدار خودکار تمام حالات در مخزن نیست.

برای تغییر TypeScript: `pnpm exec tsc --noEmit`. برای تغییر برنامه: `pnpm build`. برای صفحات ایستا، اعتبار نحو JS و لینک‌ها را بررسی کنید. ادعای تست دیداری یا E2E بدون اجرای واقعی آن نکنید.

## سناریوی پذیرش دستی

| سناریو | انتظار |
|---|---|
| بازکردن دوباره فضای تستی | عدم تکثیر نمونه‌ها و عدم بازنشانی موجودی |
| جابه‌جایی واقعی/تستی | اطلاعات یک فضا در دیگری ظاهر نشود |
| ترکیب ۷۰٪ + ۲۰٪ | خطای مجموع درصد |
| اصلاح ترکیب | نسخه تازه؛ دستور قبلی ثابت |
| فروش دو برگر ۱۵۰گرمی با ۷۰/۳۰ | ۲۱۰ گرم گاو و ۹۰ گرم گوسفند، در صورت بازده ۱۰۰٪ |
| کسری یکی از اجزا | عدم ثبت کل فروش و عدم مصرف جزء دیگر |
| تکرار درخواست همان فروش | عدم کسر دوباره |
| lot تاریخ گذشته | کنار گذاشته شود؛ موجودی فیزیکی آن همچنان دیده شود |
| دورریز از lot | مقدار و ارزش همان خرید کم شود |
| منوی عمومی | فقط نام/توضیح/دسته/قیمت؛ بدون هزینه، انبار یا رسپی |
| لینک منوی خراب | پیام خطا، بدون اجرای HTML یا نمایش داده ناقص |
| نقش نمایشی مدیر کل | رنگ بنفش؛ بدون ادعای مجوز واقعی |

## شکاف‌های شناخته‌شده

- API به ۱۰۰۰ رکورد و ۱۰۰۰ حرکت محدود است؛ گزارش تاریخی ممکن است ناقص شود.
- سقف ۲۵ تخصیص فروش و ۳۰ آیتم منوی عمومی وجود دارد.
- گزارش در مرورگر ساخته می‌شود؛ date-picker میلادی و نمایش فارسی است.
- تعداد فروش صحیح است؛ اصلاح مصرف نمی‌تواند مقدار را صفر کند.
- هزینه بسته‌بندی فروش پیش‌فرض یک پرس است و با تعداد خودکار ضرب نمی‌شود.
- ابطال ثبت اشتباهِ تولیدنشده اکنون وجود دارد؛ مرجوعی، اصلاح عمومی موجودی و timestamp دلخواه فروش هنوز وجود ندارند.
- تطبیق catalogId برند یا درصد چربی را جدا نمی‌کند.
- قیمت‌های snapshot با ثبت قیمت جدید بازمحاسبه خودکار نمی‌شوند.
- اعتبارسنجی حرفه‌ای UUID، payload hash برای idempotency و schema رسمی JSON نداریم.
- تست E2E احراز هویت، بار هم‌زمان واقعی D1، بازیابی backup و ممیزی امنیت مستقل انجام‌شده فرض نمی‌شوند.
- منوی لینک‌محور ثابت است؛ تغییر قیمت نسخه قبلی را اصلاح نمی‌کند، حذف/ابطال لینک نداریم و لینک ممکن است بلند شود.
- پنل مدیر کل فقط پیش‌نمایش است؛ رنگ‌بندی مجوز ایجاد نمی‌کند.

آزمون خودکار افزوده: voidSale، بازگشت دقیق lot، retry با همان و شناسه تازه، الزام تأیید تولیدنشدن، جداسازی مجموعه، rollback خطای میانی و عدم احیای فروش باطل‌شده در seed. مسیریابی با build و آزمون نگاشت مسیر بررسی می‌شود؛ نتیجه بررسی HTTP محیط توسعه در سند آدرس‌ها ثبت می‌شود.
